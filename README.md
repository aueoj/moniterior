# 모니테리어 (Moniterior)

바탕화면에 아이콘 대신 방을 깔아요. 방 안 사물이 진짜 폴더가 되는 Mac 앱이에요.

- 사물을 누르면 연결된 폴더가 열려요
- 파일을 사물 위로 끌어다 놓으면 그 폴더로 옮겨져요. 휴지통이면 휴지통으로 가요
- 좋아하는 사진으로 내 방을 만들고 사진 속 사물에 폴더를 연결할 수 있어요

## 받기

[최신 버전 받기](https://github.com/aueoj/moniterior/releases/latest)

- M1 이후 Mac: `Moniterior-mac-arm64.zip`
- Intel Mac: `Moniterior-mac-x64.zip`

## 설치

1. 받은 zip을 풀고 모니테리어를 응용 프로그램 폴더로 옮겨요
2. 처음 열면 경고가 떠요. 개인이 만든 앱이라 Apple 인증서가 없어서 그래요. 완료를 눌러 창을 닫아요
3. 시스템 설정의 개인정보 보호 및 보안 맨 아래에서 '그래도 열기'를 눌러요. 다음부터는 바로 열려요

파일은 내 Mac 안에서만 옮겨져요. 앱이 인터넷에 접속하는 건 새 버전이 나왔는지 확인할 때뿐이에요.
